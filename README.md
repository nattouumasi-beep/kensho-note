# 懸賞ノート（半自動・無料運用）

実用品を優先して探すための個人用ウェブサイトです。

公開サイト： https://nattouumasi-beep.github.io/kensho-note/

## 使い方

1. サイトを開くと **実用品の候補を優先** 表示します。「候補すべて」に切り替えることもできます。
2. 気になった案件は紹介記事から主催者の**公式応募先**を探して、参加資格・費用・期限・規約を確認してください。
3. **PCのChromeで使う場合**：初回のみ「設定 → 自動入力とパスワード → 住所やその他の情報」に、懸賞専用Gmail・氏名・住所・電話番号をブラウザ上で保存します。応募フォームでは保存した情報を選択できます（すべてのフォームには対応しません）。Chromeに保存するだけで、懸賞ノートやGitHubには個人情報が送られません。入力と送信は必ず本人が確認します。
4. 応募後に「応募済みにする」を押します。保存・応募済み情報は **そのブラウザ内だけ** に保存されます。バックアップは「バックアップ・設定」で行えます。

## 応募判断（2026年10月改善）

- **応募の手間**：Xの単純なリポスト中心、Webフォーム・アンケートの記載、その他を記事見出しから推定します。見出しにない追加条件は分からないため、各主催者の規約を確認してください。
- **信頼性**：現在のRSSはニュース記事へのリンクが多く、記事を配信した媒体と懸賞の主催企業は異なる場合があります。そのため、**主催企業は「公式確認前」**と表示し、企業の信頼度点数を捏造しません。公式ドメイン・企業情報・規約を確認してください。
- **当たりやすさ**：見出しに当選人数が書かれている場合、人数を参考情報として表示できます。ただし応募者数が不明なため、当選確率は算出しません。「当選人数の記載順」は、当たりやすさランキングではありません。
- 追加の有料サービスや外部APIを用いず、既存の公開データとブラウザ内の計算だけで表示します。

## 懸賞候補の自動収集

- 毎日 08:13 JST 頃に GitHub Actions が実行されます。遅れることがあります。
- PR TIMES、Google ニュースの公開RSS、懸賞情報ブログの公開RSSを利用します。通信に失敗した収集先は飛ばし、全ソースが失敗した場合は既存データを残します。
- タイトルの語句から実用品（ギフト券・家電・食品・日用品・ゲーム）を推定して優先表示します。**当選商品そのものや受付中であることを検証したわけではありません。**
- 「新規登録」「購入者限定」「レシート応募」などとタイトルに明記された候補を除外しますが、**表示された候補も登録不要とは限りません**。応募条件は常に未確認です。
- 紹介記事は応募フォームではありません。ワンクリック応募や外部サイトの事前入力は保証できません。
- RSSのみの収集なので、実用品の候補が0件になることもあります。

## プライバシーと安全性

- 氏名・住所・電話番号・メールアドレス・パスワードはサイトに入力させず、GitHub に保存しません。公開する `data/campaigns.json` は記事タイトル・記事URLなどの公開情報のみです。
- 別ドメインの応募フォームを懸賞ノートから強制操作したり、個人情報を自動送信したりしません。
- 入力が楽になるよう、iPhoneなら **設定 → アプリ → Safari → 自動入力**、Chromeなら **設定 → 自動入力とパスワード** の公式機能を利用してください。
- Xの自動フォロー/いいね/リポストや CAPTCHA 回避は行いません。
- 当選手数料、クレジットカード番号、パスワード、確認コード等を要求する怪しい案件は除外し、応募しないでください。
- 公開リポジトリなので、個人情報、検証用メールアドレス、住所をコミットしないでください。

## 構成

- `index.html`: CSS/JavaScript同梱のスマホ対応サイト
- `scripts/update_feed.py`: Python標準ライブラリだけで公開RSSから候補を収集
- `data/campaigns.json`: 公開候補データ（本人の情報はなし）
- `.github/workflows/update-campaigns.yml`: 候補収集と GitHub Pages の公開更新
- `README.md`: この説明書

**注意：** 公開サイトおよびRSS情報は各主催者によって変更されます。個人情報を送信する前に必ず主催者・応募資格・条件を確認してください。
